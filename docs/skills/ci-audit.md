# ci-audit

**Renamed to [`ci-fix`](ci-fix.md) in repo-hygiene 0.9.0.** The audit
lives on as `/ci-fix --audit`; the skill now also fixes failures with a
measured, targeted, escalating verification loop, and analyzes slow jobs with
`--optimize`. Nothing answers to the name `ci-audit` any more; existing
placements must be re-pointed to `ci-fix`.
