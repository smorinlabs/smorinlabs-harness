# Source framework and attribution

The skill is a self-contained synthesis. This file holds the provenance of every
borrowed idea and passage, so that nothing in the skill has to point outside
itself for attribution. The owner's source framework, quoted verbatim, is
design history rather than an operating rule; it lives in the repository at
`docs/superpowers/specs/2026-09-07-clear-decision-communication-source-framework.md`.
